## Han character stroke data

To write Chinese characters (漢字 · 한자), `@sveltebrush/core` downloads stroke data at runtime, one file per character, from [`hanzi-writer-data`](https://github.com/chanind/hanzi-writer-data) on jsDelivr (or from the URL passed to `setGlyphSource`).

That data comes from the [Make Me a Hanzi](https://github.com/skishore/makemeahanzi#license) project and is derived from fonts by Arphic Technology Co., Ltd. It is distributed under the Arphic Public License, whose full text ships with both projects.

If you self-host or redistribute this data, for example for offline use or a strict Content Security Policy, you must follow the Arphic Public License, including keeping its copyright notice and licence text with the data.

## Hangul

Hangul (한글) strokes are generated by Sveltebrush's own code from the jamo that make up each syllable, so no external data is used.

## Fonts in the demo

The demo site loads [Gowun Batang](https://fonts.google.com/specimen/Gowun+Batang) and [Inter](https://fonts.google.com/specimen/Inter) from Google Fonts under the SIL Open Font License. Seals use Gowun Batang when the page provides it, and the browser's serif font otherwise.
